# برنامج ماستر — الإصدار الثاني من المرجع

مرجع متطلبات نظام موحد للمبيعات والمرتجعات والتحصيلات والذمم والأهداف والعمولات والخرائط والتقارير.

| | |
|---|---|
| **إصدار التنظيم** | 0.13.0 — 2026-10-15 |
| **إصدار المحتوى** | 0.1.64 مع جولتي 8/10/2026 وجولات 10/10/2026 |
| **المرحلة** | المرحلة 3 (البناء) مكتملة الوحدات: 1–6 (التعريفات والصلاحيات، الرفع والسندات، الحسابات، الأهداف والعمولات، الخرائط، التقارير) و7 (اختبارات الحمل والأداء والاسترجاع B092–B094 على 100000 و500000 صف اصطناعي — [النتائج](docs/30-validation/load-results.md)) في `supabase/` و`app/` و`tests/`؛ التالي: القياس على Supabase الفعلي ثم الملفات الحقيقية |
| **المنصة المعتمدة** | Google AI Studio App + Supabase |
| **المصدر** | منقول من `mqtashat/MASTER-system` دون تغيير صياغة أي قاعدة |

## ترتيب الأولوية عند التعارض

جولة الاعتماد الأحدث تاريخًا ← بنود B001–B094 ← نص ملف المجال. كل ملف مجال يبدأ بتنبيه يسرد الجولات الأحدث التي تخصه.

## ضمان عدم الفقد

- كل سطر غير فارغ من الملفات الأصلية موجود في الهيكل الجديد؛ يتحقق من ذلك `tools/verify_coverage.py`.
- المصادر الخام والنسخ السابقة منقولة بايتًا ببايت.
- نسخة كاملة مجمدة من الملفات الأصلية في `docs/90-archive/v0.1.64-original/`.
