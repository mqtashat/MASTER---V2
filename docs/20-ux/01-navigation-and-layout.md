## 1. نقطة البداية حسب المستخدم

| المستخدم | صفحة الدخول المقترحة | نطاق العرض |
| --- | --- | --- |
| مدير النظام | الرئيسية | جميع البيانات والإجراءات |
| مشرف | بطاقات فريقه إن كانت مسموحة، وإلا أول صفحة مسموحة | فريقه أو قائمة مندوبيْن تحددها الإدارة |
| مندوب بصلاحية بطاقة فقط | بطاقة أدائه مباشرة | نفسه فقط؛ لا قوائم أو روابط لبيانات غيره |
| مندوب بصلاحيات أوسع | بطاقته مع الصفحات الممنوحة | نفسه فقط |
| محاسب أو مستخدم مخصص | أول صفحة عمل مسموحة مثل الذمم | النطاق الذي تحدده الإدارة |

لا تظهر صفحات ممنوعة أو أعداد إجمالية تخص غير المسموح. منح المبيعات دون الحسابات لا يكشف رصيد العميل عبر نافذة جانبية. التفاصيل المشتركة تعرض الأقسام المسموحة فقط. نطاق الفريق التاريخي/الحالي يستخدم السياسة المعتمدة مع مراجعة أمنية تمنع الوصول بالتلاعب بمعرف الموظف.

## 2. القائمة الرئيسية

| الوحدة | الوجهات |
| --- | --- |
| الرئيسية | P01 لوحة المتابعة |
| البيانات | P02 العملاء، P03 الموظفون والفرق، P04 المنتجات، P05 الرفع الموحد وسجله، P06 الفواتير/المرتجعات/التحصيلات |
| الحسابات | P07 كشف حساب العميل، P08 الذمم الحالية، P08أ الافتتاحيات والإغلاق السنوي، P09 الإشعارات |
| الأهداف والعمولات | P10 أهداف المندوبين، P10أ أهداف المشرفين، P11 قواعد العمولة، P12 المكافآت، P13 بطاقات الأداء، P14 كشف العمولات وتبويب حساباتها P14أ، P14ب الأشهر والإغلاق |
| الخرائط | P15 خريطة الفواتير والمسار، P16 مواقع العملاء، P17 المناطق والأسواق، P17أ مقارنة الفترات، P17ب انتشار الأصناف |
| التقارير | P18 تقارير الإدارة والمبيعات والتحصيل والأداء والانتشار والجودة |
| الإعدادات | P19 التقويم، P20 المستخدمون والصلاحيات، P21 إعدادات النظام وسجل العمليات |

بطاقات الأداء مدخل مستقل ظاهر ضمن الأهداف؛ الفواتير والمرتجعات والتحصيلات لها روابط مباشرة، مع غلاف جدول موحد واختلاف أعمدتها. لا صفحة FIFO منفصلة؛ توزيعه في تفاصيل الذمم والتحصيل. لا مركز رفع عام للموظفين أو المنتجات: استيراد وتصدير التعريفات من صفحاتها، والرفع الموحد للحركات الثلاث فقط.

## 3. شكل موحد لكل صفحة

1. اسم الصفحة ومسار الرجوع، ثم الفترة والنطاق وآخر تحديث مكتمل.
2. الأفعال الرئيسية الملائمة: إضافة أو رفع أو تصدير حسب الصلاحية، لا أزرار غير مرتبطة بالمهمة.
3. فلاتر أساسية ظاهرة، وفلاتر إضافية قابلة للفتح، مع عدد النتائج وزر مسح الفلاتر.
4. بطاقات ملخص قابلة للفتح في التفاصيل بنفس السياق.
5. جدول 50 أو 100 صف؛ الفرز والبحث والنطاق على الخادم، ولا تحميل كل السجلات للمتصفح.
6. الضغط على رقم السند أو الاسم يفتح تفاصيل جانبية مع خيار صفحة مستقلة؛ الرجوع يحفظ البحث والترتيب والصفحة وموضع التمرير.

**البحث:** الرقم الدقيق أولًا مع حفظ الأصفار البادئة؛ الاسم جزئي والنتيجة تحمل الرقم. لا بحث عام يتجاوز نطاق المستخدم.
**الأرقام:** المالية ثلاث منازل، الكميات أقرب صحيح، نسب حتى منزلتين دون أصفار زائدة، أرقام متابعة الأداء صحيحة بلا فواصل مثل 4500 و«متقدم بـ500». الإحداثيات والمعرفات لا تقرب. المجاميع من الدقة الأصلية.
**التواريخ:** D/M/YYYY مثل 1/12/2026، والشهور M/YYYY مثل 12/2026. كشف الحساب بتاريخ دون وقت.
**التحميل:** هيكل مؤقت، ثم نتائج؛ فشل الطلب يعرض خطأ وإعادة محاولة لا أصفارًا. غياب النتائج يعرض «لا توجد نتائج ضمن الفلاتر».
**اتساق النتائج:** تظهر نسخة التحديث؛ أثناء المعالجة لا تختلط بطاقة جديدة بجدول قديم. يحتفظ بآخر نتيجة مكتملة مع حالتها.
**التصدير:** الافتراضي كامل النتائج المطابقة، ويُسمح بتصدير الصفحة الظاهرة عند طلبه صراحة. يظهر نطاق التصدير وعدده؛ النتيجة الكبيرة مهمة خلفية قابلة للتنزيل عند اكتمالها.
**إتاحة الاستخدام:** RTL، لوحة مفاتيح وتركيز مرئي، تسمية للأزرار، رسالة الحالة مكتوبة لا لون فقط، دعم شاشة الهاتف دون إخفاء الإجراءات الأساسية. لم يتم بناء التصميم البصري بعد.
